Understanding Computation is a series about the fundamentals of programming, intended to help people without a programming background understand the basic structure of computer programs.

Corrections and feedback are always welcome.
Notes from a self-learning journey—not necessarily suitable for everyone.

In future installments, I hope to include more patch examples to make the concepts easier to understand intuitively, while continuing to expand the content on fundamental programming concepts and VL.

The image version is recommended for reading.
